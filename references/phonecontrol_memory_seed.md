# phonecontrol memory（脱敏基础经验种子）

> 这是可随 skill 分发的基础经验，不包含账号、昵称、局域网地址、个人文件路径、商品草稿或历史执行日志。首次运行时会复制到当前工作区的 `.xianyusj/phonecontrol_memory.md`。

## 公共动作卡

### open_dual_instance

- 动作：打开应用的双开选择页，默认选择第二个实例。
- 适用：存在双开/多开实例的应用。
- 成功信号：目标应用已打开，并确认是第二个实例。
- 节点规则：每次重新读取当前实例节点，不复用旧 `node_id`。
- 失败恢复：重新获取实例列表；没有第二个实例时记录 `no_second_instance`，不擅自创建或切换账号。
- 状态：候选公共经验，需要在其他应用复用后再晋升。

### refresh_current_nodes

- 动作：页面跳转、弹窗关闭或应用切换后重新获取当前节点。
- 适用：所有 phonecontrol 页面任务。
- 成功信号：后续操作使用新页面节点。
- 禁止：复用上一个页面的 `node_id`。
- 状态：通用经验。

### fast_text_input

- 动作：目标字段获得焦点后，用可用的文本注入能力快速输入。
- 适用：支持文本注入的输入框。
- 成功信号：字段存在目标文本或页面显示已输入状态。
- 失败恢复：只重新定位当前字段，不重做整个页面。
- 状态：候选公共经验，需要跨任务复用验证。

### activate_default_input

- 动作：对显示默认值、但尚未获得焦点的输入框先点击一次，确认进入输入态后再输入。
- 成功信号：输入框出现焦点/编辑态，随后输入值发生变化。
- 失败恢复：重新读取当前页面结构，只补做一次激活动作；不要连续重复点击数字键或确认键。
- 状态：候选公共经验。

## 闲鱼应用适配器

- 应用包名：`com.taobao.idlefish`。
- 普通商品默认从“卖闲置”→“发闲置（自己拍图卖·啥都能换钱）”进入；不要误走“发服务”。
- 服务商品只能在用户明确要求时进入“发服务”。
- 服务商品信息框中的示例文字必须先清空，再填写实际内容。
- 闲鱼价格目标明确且数字键盘可见时，优先直接点击目标数字并立即核验页面变化；不要默认点击清除。
- 电脑图片任务优先先在手机 Edge 中完成图片身份核验，再打开闲鱼；同一 `asset_id` 只允许一次保存请求。
- 发布成功必须以商品详情页或平台成功提示为准。

## 闲鱼图片中转经验

- 使用 Edge（包名 `com.microsoft.emmx`）作为默认浏览器。
- 中转页的“保存请求已记录”只代表服务端收到请求，不代表手机文件已经落盘。
- 应按稳定文件名、文件大小、修改时间或 hash 核验目标文件，并最终核对闲鱼表单中的目标缩略图。
- 无法确认目标图片时进入 `pending` 或 `manual_required`，不重复下载同一 `asset_id`。
