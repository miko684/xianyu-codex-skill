# 闲鱼专用 SOP

## 适用范围

当用户要求在闲鱼创建、编辑、完善或发布商品时使用本 SOP。通用控制经验由 `references/controlimprove.md` 管理。

## 强制前置

1. 必须通过可用的 phonecontrol MCP 工具操作手机界面；如果 phonecontrol 不可用，不要假装完成点击、输入或发布。
2. 先确保 `.xianyusj/phonecontrol_memory.md` 和 `.xianyusj/task_execution_log.csv` 已创建并读取；再查精确 SOP、相似任务和公共动作卡。
3. 为本次任务建立稳定 `task_id`，在第一个 phonecontrol 调用前记录开始时间；每个动作都记录开始、结束、耗时、方法、结果和重试次数。
4. 不记录 Bearer Token、密码、Cookie、验证码或完整个人数据。

## 执行原则

- 先读取当前页面状态，再操作；页面跳转、弹窗关闭、应用切换后重新读取节点，不复用旧 `node_id`。
- 优先使用语义节点，其次使用已验证的坐标；不要从一次失败的坐标点击推断新的通用坐标。
- 每个写操作都要有页面状态变化作为成功信号。工具返回“点击完成”不等于业务成功。
- 同一无效动作最多按已记录的恢复策略重试一次；连续无效时停止并报告，不盲目连点。
- 用户只要求准备或编辑时，不擅自点击最终发布；只有用户明确要求上架/发布时才提交。

## 图片任务的执行顺序

当任务需要把电脑端最新生成的图片上传到闲鱼时，必须先完成图片准备，再打开闲鱼：

1. 先在手机上打开或确认 Edge（包名 `com.microsoft.emmx`），访问本地图片中转页，确认页面展示的是最新图片。
2. 点击一次保存按钮，等待保存请求和浏览器下载确认；按稳定文件名、文件大小、修改时间或 hash 核验目标图片已经落盘。不要用图库数量变化作为唯一成功依据。
3. 图片身份确认后，才打开闲鱼并进入发布流程。
4. 如果图片已经在手机相册中，或用户明确指定使用已有图片，则跳过浏览器下载步骤；除此之外不得先打开闲鱼再回头下载图片。
5. 保存请求已发出但图片身份无法确认时，标记为 `pending` 或 `manual_required`，停止后续发布，不重复下载同一 `asset_id`。

## 闲置商品 SOP（默认入口）

1. 按“图片任务的执行顺序”完成图片前置；随后打开闲鱼并确认正确实例。存在双开时读取实例列表，按记忆中已验证规则选择。
2. 点击“卖闲置”后，只点击“发闲置（自己拍图卖·啥都能换钱）”；不要点击同一菜单中的“发服务”。
3. 进入普通闲置发布页后，确认页面是图片、宝贝描述、价格等普通商品字段；不要期待或填写“短标题”及“服务流程/服务时长/计费方式/个人优势”四行内容。如果仍出现这些字段，先停止并重新核对入口。
4. 图片只使用用户指定或已授权的本地/手机文件；描述、价格、发货方式等按用户要求填写。
5. 发布前重新读取完整表单，核对图片、描述、价格和发货方式；用户只要求测试或准备时不得点击发布。

## 闲鱼服务商品 SOP

1. 按“图片任务的执行顺序”完成图片前置；随后打开闲鱼并确认正确实例。
2. 仅当用户明确要求发布服务商品时，才进入“发服务”入口，填写标题、描述、交付周期、价格和图片；普通闲置商品不要走此入口。
   - 商品信息文本框会预填四行示例（“1. 服务流程、2. 服务时长、3. 计费方式、4. 个人优势”），必须进入该输入框后直接使用键盘 Backspace（phonecontrol 的 `DEL`）清空；不能把示例当作正式商品信息保留。
   - 清除时保持输入框焦点，按键后重新读取当前文本变化；如果一次只删除末尾一部分，就继续按 Backspace，直到四行示例全部消失，再继续填写实际商品信息。不得点击“确定”或“发布”代替清除。
3. 电脑图片优先通过包内的 `scripts/xianyu_asset_gallery.py` 上传，默认端口为 `8766`；每张图使用稳定 `asset_id`，保存请求只允许发送一次。
4. 中转页显示“保存请求已记录”只代表服务器已记录并发起一次保存请求，不代表 Android 图库索引已经完成。最终要按稳定文件名、文件大小、修改时间或 hash 查找目标文件，并以闲鱼表单中的目标缩略图槽位核验。
5. 如果同一 `asset_id` 已经请求过保存但暂时找不到目标文件，标记为 `pending` 或 `manual_required`，只继续核验，不重复下载、重复点击或改用其他相册图片。
6. 发布前重新读取完整表单，核对标题、描述、价格、交付周期和图片缩略图数量/身份。
7. 发布后必须进入商品详情或看到平台成功提示，再记录为成功。

## 价格输入规则

- 不把“清除”作为默认步骤；已验证清除节点和坐标多次无效。
- 目标价格明确且数字键盘可见时，先读取数字键语义节点，直接点击目标数字一次。
- 立即读取表单验证价格变化。已验证的 1 元路径是：点击数字 `1` 后显示 `价格设置1`，预估到手价显示 `¥0.99`。
- 如果第一次点击没有状态变化，只点击价格区域激活一次，再重新读取数字键节点并输入；不要连续重复点击。
- 如果价格显示 `.00`、数值未变或出现其他异常，标记为失败，不把 `replayed` 或“点击完成”当成价格成功。
- 粘贴、`ACTION_SET_TEXT` 或输入法注入只有在对应 phonecontrol 工具可用且字段状态可验证时使用；不可用时不要伪造粘贴结果。

## 记忆与改进

- 任务开始查找精确 SOP，再查相似任务，最后查公共动作卡。
- 新发现先写入 `.xianyusj/phonecontrol_memory.md` 的“待分类经验”。只有在至少两个不同任务或应用中成功复用后，才晋升为公共经验。
- 闲鱼价格、商品字段、类目、发布入口和具体坐标留在闲鱼专用 SOP，不写入公共动作卡。
- 图片中转任务结束时额外记录 `asset_id`、保存请求状态、是否收到下载请求以及最终缩略图核验结果；补写任务总耗时、成功/失败原因和下一次可复用的恢复策略。

## 停止条件

遇到认证失效、页面与预期不符、价格连续无变化、目标 `asset_id` 无法确认、图片缩略图无法核验、发布结果无法确认或用户要求暂停时，停止外部写操作并报告事实、已完成步骤和 `.xianyusj/` 中的日志位置。保存请求已发出但观察不到目标文件时，不自动重试同一图片。
